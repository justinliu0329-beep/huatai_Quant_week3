## 一、策略设计

- **有效因子**（Week1 筛选，|t|>2）：volatility_20, turnover_20, pb, momentum_20, reversal_5
- **合成方式**：IC 加权，score = Σ(IC_f · z_f)/Σ|IC_f|。权重：{'volatility_20': -0.0745, 'turnover_20': -0.0652, 'pb': -0.049, 'momentum_20': -0.0444, 'reversal_5': -0.0319}
- **选择理由**：各因子 IC 量级差异大（波动率 -0.075 显著强于反转 -0.032），等权会稀释强因子；IC 加权按预测力配比，信息利用更有效。
- **调仓**：周度（每周最后交易日打分，次日起生效，符合 T+1）
- **持仓约束**：8~20 只等权；单票 ≤15%；单行业 ≤30%
- **成交成本**：佣金 0.03%(双边) + 印花税 0.05%(卖出) + 滑点 0.05%，逐笔按成交额核算
- **止盈止损**：单票 -10% 止损 / +20% 止盈（持有期每日检查）
- **回测框架**：VectorBT（撮合/净值） + 自研调仓与成本模型
- **累计交易成本**：446,892 元
